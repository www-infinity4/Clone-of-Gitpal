📖 All Commands

Six powerful commands to supercharge your Git workflow.

✏️
gitpal commit
commit

Reads your staged diff and generates a meaningful conventional commit message using AI.

git add src/payment.js
gitpal commit

✔ Commit message generated!
  feat(payment): integrate Razorpay
? Use this message? Yes ✅
🔍
gitpal review
review

AI reviews your staged code for bugs, security issues, and bad practices before you commit.

git add .
gitpal review

🐛 Bugs Found:
  - No error handling on login fail
🔒 Security Issues:
  - Password stored as plain text
❌ Verdict: Do not commit
📋
gitpal summary
summary

Summarizes your recent commits in plain English so you always know what you built.

gitpal summary --last 7

📋 Summary of last 7 commits:
• Built user auth with JWT tokens
• Integrated Razorpay gateway
• Fixed cart total calculation
• Added dark mode to dashboard
📝
gitpal pr
pr

Generates a complete PR description from your branch diff. Copy-paste straight into GitHub.

gitpal pr --base main

📝 Pull Request Description:

## What changed
- Integrated Razorpay payment
- Added webhook handler

## Why
- App needed real payment processing
📄
gitpal changelog
changelog

Auto-generates a formatted CHANGELOG entry from your commit history.

gitpal changelog --ver 2.0.0

📄 CHANGELOG v2.0.0:

## [2.0.0] - 2026-03-24
### Features

- Fixed cart calculation

git add .
